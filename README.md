# Predicting Three-Year Recidivism Using Correctional Data
This project applies exploratory data analysis, machine learning and interactive data visualization to examine factors associated with three-year recidivism using correctional data.
The study analyses 25,835 records and compares three classification algorithms—Logistic Regression, Decision Tree and Random Forest—to determine which provides the strongest predictive performance among the models evaluated.

## Limitations

The study has several limitations:

1. The models do not provide perfect predictions.
2. The study identifies predictive relationships and associations rather than causation.
3. False-positive and false-negative classifications remain.
4. Some categorical groups may contain relatively small numbers of observations.
5. Feature importance should not be interpreted as causal importance.
6. The study did not establish external validation using an independent dataset.
7. Further model optimization and fairness assessment could strengthen future research.

## Future Research

Future work could include:

- Hyperparameter optimization
- Cross-validation
- Evaluation of additional machine-learning algorithms
- Explainable AI techniques
- Fairness and bias assessment
